# Licence texts the Action bundle adds to a package's own

`scripts/licenceBanner.ts` appends these to the banner entry of the package named.

- `resvg-wasm.LICENSE` (`@resvg/resvg-wasm`, MPL-2.0): the package publishes no licence file. This is the MPL-2.0 text
  of the same project (`yisibl/resvg-js`), as `@resvg/resvg-js` ships it. Source: https://github.com/yisibl/resvg-js.
- `resvg-wasm-crates.txt` (`@resvg/resvg-wasm`): every Rust crate compiled into `resvg.wasm`, its exact version and
  licence, and the licence files it ships, verbatim (a crate that ships none: the SPDX text with the authors from its
  Cargo.toml, marked as such). Generated by `node packages/action/scripts/resvgCrates.ts` (Node 24, network): resvg-js
  commits no Cargo.lock, so the script resolves the graph of resvg-js 2.6.2 for wasm32 from the crates.io index as on
  2024-03-26, with the versions the binary names pinned, and reads each `.crate`. Rerun it when `@resvg/resvg-wasm`
  changes version.
- `libwebp-COPYING`, `libwebp-PATENTS` (`wasm-webp`, MIT): `webp-wasm.wasm` is libwebp (BSD-3-Clause), built from
  webmproject/libwebp at 6c484cbf (v1.3.2 plus 135 commits); these are that release's `COPYING` and `PATENTS`.

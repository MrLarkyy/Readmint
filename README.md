# Readmint

**Design your README. Any font, any data, any style.**

Readmint renders README graphics from designs you make yourself: your own layout, your own fonts, GIFs and
animation, bound to live data through placeholders — including a contribution calendar you can shape any way you like.
Output is SVG, PNG, animated WebP, APNG or GIF, generated by a GitHub Action in your own repository.

Status: early development.

User guide: [the wiki](https://github.com/MrLarkyy/Readmint/wiki), generated from `docs/`
([how it is published](docs/wiki-publishing.md)).

Set up the GitHub Action: [docs/action.md](docs/action.md).
Contribution calendar, starter templates (stats card, isometric card, banner, language bars, profile card, light and
dark) and three full profile templates (Year Ring, Horizon, Pinscreen): [docs/components.md](docs/components.md).
